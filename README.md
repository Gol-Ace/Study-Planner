# Study Planner 
A responsive study planner web application designed to help students organize their studies, manage tasks and exams, as well as track their study progress.
## Features
- Manage subjects
- Create and manage study tasks
- Manage exams
- Track study progress
- Save data using browser local storage
- Responsive design for different screen sizes
- Modern interface with animations
## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage
## Project Status
This is the frontend version of Study Planner. A backend and database can be added in future versions to provide features such as persistent online data and user accounts.
## How to run
1] Download or clone this repository.
2] If downloaded as a ZIP file then extract it.
3] Open 'index.html' in a web browser.
